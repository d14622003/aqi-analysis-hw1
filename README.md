# 🌍 AQI 避難收容處所風險分析系統

## 📋 專案概述

本專案結合空氣品質指數（AQI）與避難收容處所資料，建立一套完整的空間風險分析系統。透過即時 AQI 數據與避難所位置的空間關聯分析，評估各避難所在不同空氣品質狀況下的風險等級，並提供互動式地圖視覺化。

### 🎯 專案目標
- 整合環境部即時 AQI 監測數據
- 清理與驗證避難收容處所座標資料
- 執行空間最近鄰分析，建立避難所與測站的關聯
- 評估避難所風險等級（高風險/警告/正常）
- 生成交動式地圖，區分室內外避難所並標示風險狀態

## 🔄 處理流程

### 第一階段：資料清理與驗證 (`process_shelters.py`)

1. **資料讀取與路徑設定**
   - 使用相對路徑邏輯，確保跨平台相容性
   - 讀取原始避難所 CSV 檔案與台灣縣市界線 Shapefile

2. **座標品質檢查**
   - 檢測經緯度數值缺失或錯誤（值為 0）
   - 驗證座標是否在台灣地理範圍內
   - 檢查經緯度小數點精度與合理性
   - 判斷座標系統（TWD97 vs WGS84）

3. **空間位置驗證**
   - 使用 GeoPandas 進行空間交集分析
   - 檢查避難所是否落在對應的行政區內
   - 標記座標有效性（有效/無效）

4. **資料清理輸出**
   - 生成 `shelters_cleaned.csv`，包含座標有效性欄位
   - 移除無效座標的記錄，確保後續分析品質

### 第二階段：AQI 整合與風險分析 (`shelter_aqi_analysis.py`)

1. **即時 AQI 數據獲取**
   - 透過環境部 API 獲取全台 AQI 測站即時數據
   - 資料預處理與型態轉換
   - 執行情境注入測試（第5個測站 AQI 設為 150）

2. **空間最近鄰分析**
   - 使用 Haversine 公式計算球面距離
   - 為每個避難所找到最近的 AQI 測站
   - 記錄距離與對應測站資訊

3. **風險評估邏輯**
   ```
   風險分級規則：
   - 高風險 (High Risk)：AQI > 100
   - 警告 (Warning)：AQI > 50 且為室外避難所
   - 正常 (Normal)：其他情況
   ```

4. **互動式地圖生成**
   - 建立 Folium 互動式地圖
   - 區分室內（🏠）與室外（🏢）避難所圖標
   - 根據風險等級使用不同顏色（紅/橙/藍）
   - 顯示完整資訊：名稱、類型、風險、最近測站、座標

## 🛠️ 技術實作細節

### 主要套件與工具
- **資料處理**：pandas, numpy, geopandas
- **地理計算**：shapely, Haversine 公式
- **視覺化**：folium, MarkerCluster
- **API 整合**：requests, python-dotenv
- **檔案管理**：pathlib

### 關鍵技術挑戰與解決方案

1. **座標系統混亂問題**
   - **問題**：原始資料混合 TWD97 與 WGS84 座標系
   - **解決**：建立邊界檢查邏輯，自動偵測並標記異常座標

2. **資料品質不一致**
   - **問題**：缺失值、小數點精度錯誤、經緯度為 0
   - **解決**：多層次驗證機制，包含數值範範圍、邏輯一致性檢查

3. **空間關聯分析效能**
   - **問題**：大量避難所與測站的距離計算
   - **解決**：使用向量化運算，優化 Haversine 計算

4. **互動式地圖資訊過載**
   - **問題**：標記點過多導致地圖混亂
   - **解決**：使用 MarkerCluster 分群顯示，依風險等級分層

### 開發注意事項

1. **路徑管理**：使用 `pathlib.Path` 確保跨平台相容性
2. **錯誤處理**：完善的 try-catch 機制，避免 API 失敗導致程式中斷
3. **記憶體管理**：大型 CSV 檔案的分批處理
4. **設定檔分離**：API 金鑰等敏感資訊使用 `.env` 檔案管理

## 🚀 使用方式

### 環境設定
1. 安裝所需套件：
   ```bash
   pip install pandas numpy geopandas shapely folium requests python-dotenv
   ```

2. 設定環境變數：
   - 在 `scripts/.env` 檔案中加入：
     ```
     MOENV_API_KEY=你的環境部API金鑰
     ```

### 執行步驟

1. **資料清理階段**：
   ```bash
   cd scripts
   python process_shelters.py
   ```
   - 輸出：`data/shelters_cleaned.csv`

2. **AQI 分析與地圖生成**：
   ```bash
   python shelter_aqi_analysis.py
   ```
   - 輸出：`outputs/shelter_aqi_analysis.csv`
   - 輸出：`outputs/integrated_risk_map.html`

3. **查看結果**：
   - 開啟 `outputs/integrated_risk_map.html` 查看互動式地圖
   - 檢查 `outputs/` 目錄下的分析報告
